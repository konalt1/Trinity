# Panorama UI

## Рабочий процесс

1. Перед изменением найти layout в `Content/panorama/layout/custom_game/` и проверить, как он подключён через `custom_ui_manifest.xml` или родительский XML.
2. Прочитать вместе XML, все подключённые JS и CSS: они образуют один контекст панели.
3. Сохранять существующие соглашения компонента и не обращаться к панелям другого layout через локальный `$()`.
4. После правки проверить компиляцию XML/CSS, сообщения Panorama debugger и поведение hot load. Для уничтоженной или ещё не созданной панели пересоздать её.

## Layout root

Помещать в `<root>` ровно одну верхнеуровневую `Panel`. Не задавать ей `id`: layout с `id` на корневой панели не компилируется.

## JavaScript и контексты

- Считать, что скрипт выполняется один раз при создании layout. Отдельного ready/loaded event нет.
- Размещать инициализацию в конце файла, после функций, которые она вызывает.
- Помнить, что `$("#Id")` ищет только в поддереве `$.GetContextPanel()`. Панели другого layout и встроенного HUD так не видны.
- Считать каждый layout отдельным JS scope. Верхнеуровневые `const`, `var` и `function` общие только для файлов из `<scripts>` одного layout.
- Передавать функции между контекстами через `GameUI.*`, состояние — через `GameUI.CustomUIConfig()`.
- Использовать `GameUI.CustomUIConfig()` для состояния, которое должно пережить повторное выполнение файла при hot load.

```js
const CONTEXT = $.GetContextPanel();
const config = GameUI.CustomUIConfig();
```

## Hot load

Сохранение живых `.xml`, `.js` и `.css` автоматически перезагружает ресурс. Новая генерация скрипта заменяет предыдущую: зарегистрированные старой генерацией callbacks не накапливаются. Hot load работает, только пока соответствующая панель существует и ресурс принадлежит её контексту.

## Фокус клавиатуры

- Пока панель удерживает input focus, стандартные игровые keybinds подавлены.
- Регистрировать клавишу через `$.RegisterKeyBind(panel, "key_x", callback)`; callback работает только при фокусе на переданной панели.
- Сбрасывать фокус вручную через `$.DispatchEvent("DropInputFocus")`, если UI больше не должен перехватывать клавиатуру.
